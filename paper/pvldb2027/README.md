# PVLDB 2027 Typeset Baseline

This directory vendors the official PVLDB Volume 20 / VLDB 2027 template at upstream commit `39c95f5c6fcbe652a83be24e4eff8f2134cd3fbc` (2026-07-13).

The authoritative page-budget scientific source is `docs/paper-full-draft-v4-page-budget.md`. `main.tex` is a mechanical typesetting conversion generated by:

```text
python3 convert_from_markdown.py
```

Build from this directory using the official sequence:

```text
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
cd build
BSTINPUTS=..: BIBINPUTS=..: bibtex main
cd ..
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
cp build/main.pdf main.pdf
```

F1--F4 are final deterministic vector figures. Author, affiliation, DOI, and page metadata remain explicit placeholders. The artifact URL uses the public project repository through the official `\vldbavailabilityurl` mechanism.

## Rebuilding figures

Dependencies are Python 3 and Matplotlib 3.6 or later. From the repository root run:

```text
MPLCONFIGDIR=/tmp/ce-replay-matplotlib python3 paper/pvldb2027/figures/src/build_figures.py
```

The script reads frozen repository artifacts directly:

- `results/paper-evaluation-figure-table-data-v0.json`;
- `results/census_analyze_cost_model_v0.csv`;
- `results/dmv_analyze_cost_model_v0.csv`.

It emits the eight expected `figures/f1-*.{pdf,svg}` through `figures/f4-*.{pdf,svg}` assets. The build contains no randomness, network access, or manually edited empirical coordinates. Re-running it should reproduce the same visual geometry and values; PDF metadata or backend serialization details may differ across Matplotlib versions.
