# PVLDB 2027 Typeset Baseline

This directory vendors the official PVLDB Volume 20 / VLDB 2027 template at upstream commit `39c95f5c6fcbe652a83be24e4eff8f2134cd3fbc` (2026-07-13).

The authoritative scientific source is `docs/paper-full-draft-v3-polished.md`. `main.tex` is a mechanical typesetting conversion generated by:

```text
python3 convert_from_markdown.py
```

Build from this directory using the official sequence:

```text
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
cd build
BSTINPUTS=..: BIBINPUTS=..: bibtex main
cd ..
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
cp build/main.pdf main.pdf
```

F1--F4 are deliberately neutral double-column occupancy placeholders. They preserve intended approximate aspect ratio and full frozen captions; they are not final visualizations. Author, affiliation, DOI, and page metadata remain explicit placeholders. The artifact URL uses the public project repository through the official `\vldbavailabilityurl` mechanism.
